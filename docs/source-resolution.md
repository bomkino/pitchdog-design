## Material conflicts resolved

### Typography

The August skill promoted Neco, Erode, Geist Mono, and Geist Sans into a local canonical profile. The current owner has a separate governed type-system repository.

Resolution: the type-system repository is the sole authority. The design skill contains only resolution and consumption rules. Existing artifacts preserve their immutable pin until migration is authorized. New work corroborates the declared version across repository authorities, verifies the matching tag and commit, records that identity, and pins it. Family names, role values, scales, measures, wrapping rules, CSS, and binaries are not copied here.

At inspection time the type-system tag was ahead of its GitHub Release object, so releases/latest was stale. The design skill therefore never uses main or releases/latest as an implementation pin.

The repository was publicly visible while several of its documents still described private access. Visibility does not grant a licence: the design skill links to the authority but redistributes none of its tokens, CSS, documentation, artwork, or fonts.

### Website generations

V19 is later than v16 and governs the durable design grammar. The complete handover is strong implementation evidence but contains page-specific recipes and some conflicting implementation choices.

Resolution: migrate relationships and judgment—quiet field, loud work, one strange little thing; proof sovereignty; one primary event per authored scene; clear hierarchy for dense tools; meaningful empty space; component-as-instrument; static-first motion; authored phone. Do not migrate exact page sequence, named scenes, palettes, breakpoints, sticky heights, component names, copy, or prototype CSS.

### Grain

Some later specification and implementation material introduced global grain, while a v19 self-audit rejected it. The current owner explicitly rejected grain.

Resolution: one authoritative material boundary lives in references/colour-and-material.md. Additive grain, film grain, noise, SVG turbulence, distressed-paper overlays, and pseudo-texture are forbidden. Texture intrinsic to approved source art is preserved without amplification. Tactility comes from real material and compositional evidence.

### Theme

The old skill treated dark mode as one optional authored state. The current owner requires both modes with System default.

Resolution: every new digital artifact receives System, Light, and Dark choices; System is initial, explicit overrides persist until reset, and Light/Dark values are independently authored through semantic roles. Existing-artifact scope is not silently expanded during review or surgical refinement.

### Icons

The old skill had no governed icon family. The current owner selected Phosphor.

Resolution: Phosphor is the sole Brand Mode default and the unbranded default. External brands keep an accepted icon authority; when none exists, Phosphor is provisional. Consuming projects pin the official adapter and import only what they use.

### Evaluation

The previous report treated case definitions as passed behavioural evidence and celebrated counts.

Resolution: evals/evals.json is a prompt specification. Structural validation checks package and hard authority boundaries. Behavioural cases are only reported as run when a fresh agent actually executes them and its failure modes are inspected.

## Architecture decision

SKILL.md contains the universal operating spine and checkable completion criteria. Branch-only knowledge is directly linked and one level deep:

- typography authority;
- digital theme and icons;
- Website v12 design language;
- colour and material;
- design-system governance;
- spacing and responsive authorship;
- motion;
- non-web translation;
- external-brand routing;
- artifact review.

The system standardizes authority, semantics, access, and repeatable behaviour. It leaves narrative composition authored.

## Distribution boundary

The packaged skill is text-only and below 1 MB. It contains no font, image, executable, private path, private source material, secret, telemetry, or external tool declaration. Linked authorities retain their own terms.
